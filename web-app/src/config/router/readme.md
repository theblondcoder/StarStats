Aqui es donde se van a poner todos los "exports" almacenados en constantes para cada uno de ellos, que contendrá los path de cada ruta de la web. Habrá un export por cada "page" que haya.

La idea de hacer esto, es evitar tener que estar escribiendo el "/" ruta cada vez que quiera utilizar, para ello utilizamos la constante y con la función "generate-path" podremos pasarle parámetros dinamicos en el path.
